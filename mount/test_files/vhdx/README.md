# Triage-layout NTFS fixture

`sample.vhdx.gz` is copied unchanged from Yamato Security Juntei,
commit `7c0cd8ce1e2119c4da76e5af39c6ca1a75839c34`. It is generated by Juntei's
[`make_sample.py`](https://github.com/Yamato-Security/juntei/blob/7c0cd8ce1e2119c4da76e5af39c6ca1a75839c34/test_files/vhdx/make_sample.py).

The fixture contains synthetic resident, sparse, fragmented, compressed and Unicode-named files,
plus Juntei's existing public Prefetch, Task Scheduler EVTX and Windows Server 2019 UAL fixtures.
The original fixture provenance is retained in Juntei's corresponding `test_files` directories.
It contains no private CTF evidence. The mounting tests compare all file contents to their known
SHA-256 values and modify only new temporary copies when testing corruption.
